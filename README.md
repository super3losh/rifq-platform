# 🌟 منصة رِفق - Rifq Platform

**منصة إدارة مشاريع تطوعية شاملة لمكافحة تعاطي المخدرات بذكاء اصطناعي**

---

## 📋 نظرة عامة

منصة رِفق هي نظام متكامل لإدارة المشاريع التطوعية والمجتمعية في مجال الوقاية من تعاطي المخدرات والإدمان. تجمع المنصة بين:

- 👥 إدارة المتطوعين والفريق
- 📊 تتبع المشاريع والمهام
- 🤖 ذكاء اصطناعي للتحليل والتوصيات
- 📈 تقارير وإحصائيات متقدمة
- 💬 نظام تواصل ودعم
- 🔐 أمان وخصوصية عالية

---

## ✨ الميزات الرئيسية

### 1️⃣ الذكاء الاصطناعي المدمج
- **AI Analysis**: تحليل ذكي لبيانات المشاريع والمتطوعين
- **Smart Recommendations**: توصيات ذكية لتحسين الأداء
- **Predictive Analytics**: التنبؤ بنتائج المشاريع
- **Chatbot Support**: دردشة ذكية للدعم والاستشارة
- **Sentiment Analysis**: تحليل المشاعر في التقارير والملاحظات
- **Case Matching**: ربط الحالات مع المتطوعين المناسبين

### 2️⃣ إدارة المشاريع
- إنشاء وتتبع المشاريع التطوعية
- توزيع المهام والمسؤوليات
- جدولة الفعاليات والأنشطة
- إدارة الميزانية والموارد

### 3️⃣ إدارة المتطوعين
- تسجيل المتطوعين وإدارة ملفاتهم
- تتبع ساعات العمل والإنجازات
- نظام تقييم وتحفيز
- برنامج النقاط والمكافآت

### 4️⃣ إدارة الحالات
- تسجيل وتتبع حالات المستفيدين
- جلسات الدعم والاستشارة
- ملفات طبية وسجلات آمنة
- إحالات متخصصة

### 5️⃣ اللوحات والتقارير
- لوحة معلومات شاملة
- رسوم بيانية وإحصائيات
- تقارير شهرية وسنوية
- قياس الأثر الاجتماعي

## 🛠 التقنيات المستخدمة

### Frontend
- **React.js** - واجهة المستخدم
- **Tailwind CSS** - التصميم
- **Redux** - إدارة الحالة
- **Chart.js / Recharts** - الرسوم البيانية
- **Axios** - الاتصالات

### Backend
- **Node.js + Express** - خادم الويب
- **JWT** - المصادقة
- **OpenAI API / Claude API** - الذكاء الاصطناعي
- **Multer** - رفع الملفات
- **Nodemailer** - البريد الإلكتروني

### Database
- **PostgreSQL** - قاعدة البيانات الرئيسية
- **Redis** - التخزين المؤقت

### أدوات إضافية
- **Docker** - التحزيم
- **GitHub Actions** - CI/CD
- **Vercel / Render** - الاستضافة

## 🚀 البدء السريع

### المتطلبات
- Node.js 18+
- PostgreSQL 12+
- npm أو yarn
- مفتاح OpenAI API (للذكاء الاصطناعي)

### التثبيت

```bash
# 1. استنساخ المستودع
git clone https://github.com/super3losh/rifq-platform.git
cd rifq-platform

# 2. إعداد Backend
cd backend
npm install
cp .env.example .env
# عدّل متغيرات البيئة في .env

# 3. إعداد Frontend
cd ../frontend
npm install
cp .env.example .env

# 4. إعداد قاعدة البيانات
cd ../database
psql -U postgres -f schema.sql

# 5. تشغيل Backend
cd ../backend
npm run dev

# 6. تشغيل Frontend (في terminal آخر)
cd ../frontend
npm start
```

## 🤖 ميزات الذكاء الاصطناعي

### 1. تحليل الحالات الذكي
يستخدم AI لتحليل حالات المستفيدين وتقديم توصيات شخصية:
```
Input: وصف الحالة من المختص
Output: 
- تصنيف المستوى (خفيف/متوسط/شديد)
- توصيات العلاج
- المتطوعون المناسبون
- خطة متابعة مقترحة
```

### 2. توقع احتياجات المشاريع
يتنبأ بنتائج المشاريع والتحديات:
```
- توقع معدل نجاح المشروع
- تنبيهات عن احتمالية التأخير
- توصيات لتحسين الأداء
- تحديد الفرص المتاحة
```

### 3. مساعد افتراضي (Chatbot)
- إجابة على الأسئلة الشائعة
- توجيه المستخدمين
- دعم متعدد اللغات
- تعليم وتثقيف

### 4. تحليل المشاعر
- تحليل ملاحظات المتطوعين
- كشف علامات الإجهاد أو الإحباط
- تنبيهات للمديرين
- تحسين بيئة العمل

### 5. مطابقة ذكية (Matching)
- ربط الحالات مع المتطوعين المناسبين
- تحديد الفريق الأمثل للمشروع
- توصيات الشراكات
- تحديد الموارد المطلوبة

### 6. توليد التقارير
- تلخيص البيانات تلقائياً
- توليد رسوم بيانية
- توصيات مستندة إلى البيانات
- توقعات للمستقبل
